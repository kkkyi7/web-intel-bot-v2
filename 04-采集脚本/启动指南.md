# 5 分钟启动指南

> 这份脚本不需要 n8n、不需要服务器、不需要 Docker。
> 你只需要 Python + 2 个 API Key + 邮箱授权码。

---

## 第 1 步：装 Python（如果还没装）

1. 打开 https://www.python.org/downloads
2. 下载最新版（3.11 或 3.12）
3. 安装时**务必勾选** `Add Python to PATH`
4. 打开 PowerShell 或 cmd，敲 `python --version`，能看到版本号就说明装好了

> 已经装过的跳过这一步。

---

## 第 2 步：装依赖（一次性）

双击本目录里的 **`setup.bat`**，等它跑完。

如果 setup.bat 提示 pip 报错（很少见），可以手动跑：
```
pip install -r requirements.txt
```

---

## 第 3 步：申请 2 个 API Key + 邮箱授权码

### A. YouTube Data API Key（免费）

1. 打开 https://console.cloud.google.com
2. 顶部"选择项目" → "新建项目" → 名字写 `web-intel-bot`
3. 左侧菜单 → "API 和服务" → "库" → 搜 **YouTube Data API v3** → 启用
4. 左侧 → "凭据" → "创建凭据" → "API 密钥"
5. 复制下来（`AIzaSy...` 开头）

### B. 大模型 API Key（用于摘要+打分）

> **重要**：你订阅的 Claude Max 是「网页/桌面 App 用量」，**不包含 API 调用**。API 是另一套账号、单独计费。
> 所以这一步要么花国际信用卡走 Claude API，要么走更便宜的国产 API（**强烈推荐**）。

#### 路线 A · DeepSeek（推荐，最便宜，支付宝直充）

1. 打开 https://platform.deepseek.com，注册登录
2. 左侧"API Keys" → "Create new API key" → 复制下来（`sk-...` 开头）
3. 左侧"充值" → 用支付宝充 ¥10（按 `daily_digest.py` 一天 100 条左右的用量，够用 **2-3 个月**）
4. **价格参考**：输入 ¥0.5 / 百万 tokens，输出 ¥1.5 / 百万 tokens（比 Claude Haiku 便宜 ~10 倍，中文质量比 Haiku 好）

> 不喜欢 DeepSeek？也可以换通义千问 Qwen / Kimi / 智谱 GLM-4-Flash（其中智谱 GLM-4-Flash 对个人用户**完全免费**）。
> 注册地址和示例配置都写在 `.env.template` 里，把对应的注释取消即可。

#### 路线 B · Anthropic Claude API（备选，要国际信用卡）

1. 打开 https://console.anthropic.com
2. 注册登录后 → 左侧 "API Keys" → "Create Key"
3. 复制下来（`sk-ant-...` 开头，**只显示一次**）
4. 左侧 "Billing" → 绑卡 → 充值 $5（按当前用量够用 1-2 个月）
5. 在 `.env` 里把 `LLM_PROVIDER` 改成 `anthropic`，并把 Claude Key 填进 `LLM_API_KEY`

### C. 邮箱授权码（不是登录密码）

- **Gmail**：https://myaccount.google.com/apppasswords → 生成应用专用密码
- **163 邮箱**：邮箱设置 → POP3/SMTP/IMAP → 开启服务 → 拿到的"授权码"
- **QQ 邮箱**：设置 → 账户 → 开启 SMTP 服务 → 授权码

> 不想发邮件也行，跳过这步，脚本会把 HTML 报告存到 `05-数据样本/日期/digest.html`，你直接用浏览器打开看。

---

## 第 4 步：填 .env 文件

1. 把 `.env.template` 复制一份，改名叫 `.env`
2. 用记事本打开，把里面的 `xxx` 替换成你的真实 Key：
   - `YOUTUBE_API_KEY=` 填 A 里拿到的 YouTube Key
   - `LLM_PROVIDER=deepseek`（默认就是这个，用别的才要改）
   - `LLM_API_KEY=` 填 B 里拿到的大模型 Key
   - 邮件那一段填 C 的授权码（不用邮件就留空，脚本会只存本地 HTML）
3. 保存

### 换大模型提供商？

只要改 `.env` 里的 `LLM_PROVIDER` 这一行，支持的值：
- `deepseek`（默认，最便宜）
- `qwen`（阿里通义千问）
- `kimi`（月之暗面）
- `zhipu`（智谱 GLM-4-Flash，个人免费）
- `anthropic`（Claude API，要国际卡）

代码不用改，换了以后把对应的 `LLM_API_KEY` 替换成新平台的 Key 即可。

---

## 第 5 步：跑！

### 第一次跑：建议先跑调试模式

双击 **`run_dry.bat`** —— 这个不会发邮件，只把 HTML 存到本地，你可以先看看效果。

跑完后去 `..\05-数据样本\<今天日期>\digest.html`，用浏览器打开看。

### 正式跑（带邮件）

双击 **`run.bat`**。

### 只跑某个主题（调试用）

打开 cmd，进到本目录：
```
python daily_digest.py --topic 供应链
```

## 第 6 步：定时自动运行（Windows 任务计划）

1. 按 `Win + R`，输入 `taskschd.msc` 回车
2. 右侧 → "创建基本任务"
3. 名称：`web-intel-bot 每日 Brief`
4. 触发器：每天 → 早上 8:00
5. 操作：启动程序
6. 程序或脚本：浏览到 `C:\Claude\web-intel-bot\04-采集脚本\run.bat`
7. 完成

电脑开机且联网时，每天 8 点自动跑一次。

## 常见问题

### Q1: setup.bat 闪退看不到错误？
打开 cmd，cd 到本目录，手动跑：`setup.bat`，错误信息就会留在窗口里。

### Q2: LLM_API_KEY 报错？
- 检查 .env 文件里有没有多余的空格、引号
- DeepSeek 的 Key 是 `sk-` 开头；Claude 的是 `sk-ant-` 开头；智谱是 `xxxx.xxxx` 带点的格式
- `LLM_PROVIDER` 的值必须和 Key 匹配（deepseek/qwen/kimi/zhipu/anthropic）
- 平台上要有余额（DeepSeek 新用户有时送一点试用额，用完会报 `insufficient balance`，去充 ¥10 就行；智谱 GLM-4-Flash 个人免费不用充值）

### Q3: YouTube 返回 0 条？
- 检查 .env 里 KEY 对不对
- console.cloud.google.com 里看 YouTube Data API 是否启用
- 配额（quota）每天 10000，正常用法用不完，但如果你跑了几十次会爆

### Q4: 字幕都失败？
- youtube-transcript-api 偶尔会抽风（YouTube 反爬升级）
- 不影响整体流程，没字幕的视频会用标题+频道信息让 Claude 摘要
- 实在不行升级一下：`pip install -U youtube-transcript-api`

### Q5: Reddit 403？
- Reddit 对无认证请求频率敏感
- 脚本已经加了 1 秒间隔
- 如果还是 403，把 `config.yaml` 里 reddit 的 subreddits 数量减少

### Q6: 邮件发不出去？
- 99% 的情况是用了登录密码而不是应用授权码
- Gmail 必须先开两步验证才能生成应用密码
- 端口要对：SSL 用 465，TLS 用 587

### Q7: 想加新的源/新的话题？
- 改 `config.yaml`，照着现有结构加
- 改完不用重启，下次运行自动生效

### Q8: 想让摘要更准/更短/输出别的格式？
- 打开 `daily_digest.py`，搜 `SUMMARY_PROMPT`，直接改那段提示词
- 改完保存就行

## 文件清单

```
04-采集脚本/
  daily_digest.py     ← 主脚本（不用改）
  config.yaml         ← 改这里加/减主题和源
  .env.template       ← 复制成 .env 填 Key
  .env                ← 你自己填的（不要分享）
  requirements.txt    ← Python 依赖清单
  setup.bat           ← 一键装依赖
  run.bat             ← 一键运行（带邮件）
  run_dry.bat         ← 调试运行（不发邮件）
  启动指南.md         ← 你正在看的这份
```

```
05-数据样本/
  2026-04-21/
    all.json          ← 当日所有抓取条目（含未通过筛选的）
    digest.html       ← 当日精选 Brief（同邮件内容）
  2026-04-22/
    ...
```
