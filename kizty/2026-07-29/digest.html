【一句话讲清楚它在说啥】
阿里开源了一个内部用了两年的 AI 代码审查 CLI 工具，用确定性工程加 LLM Agent 的混合架构，比通用 Agent 更准、更快、更省 token，已在几十万开发者中验证过。
【详细讲给你听】
背景是，阿里集团内部过去两年一直在用一套 AI 代码审查助手，服务了几万名开发者，发现了数百万个代码缺陷。现在他们把这套工具开源了，叫 Open Code Review。核心设计很有意思：不是纯靠大模型，而是把确定性工程和 LLM Agent 混在一起。确定性工程负责那些必须准确的部分，比如精确选择哪些文件需要审查、把相关文件打包、生成行级别的评论位置。LLM Agent 则负责深度理解代码上下文、搜索代码库、跨文件分析。这种架构解决了通用 Agent 的几个痛点：审查不完整、位置漂移、质量不稳定。关键数据很亮眼：跟 Claude Code 比，在相同模型下 Precision 和 F1 显著更高，token 消耗只有约九分之一，审查速度更快。当然 Recall 略低，这是有意为之，宁可漏报也不要误报。基准测试用了 50 个流行开源仓库、200 个真实 PR、10 种编程语言，由 80 多位资深工程师交叉验证了 1505 个标注问题。工具支持 OpenAI 和 Anthropic 的模型，直接配置模型端点就能用。
【关键术语小词典】
- Precision / 精确率：报告的问题中真正是缺陷的比例，越高误报越少
- Recall / 召回率：实际缺陷中被找到的比例，越高漏报越少
- F1 / F1 分数：精确率和召回率的调和平均，衡量审查质量的综合指标
- LLM Agent / 大模型智能体：能自主调用工具、搜索代码库、理解上下文的 AI 程序
【对你有啥用】
1. 产品判断：这个“确定性工程 + Agent”的混合架构思路，可以直接迁移到你做的排程算法产品里。排程中那些必须精确的约束（比如设备产能、物料 BOM），用确定性逻辑保证；而复杂优化目标（比如多目标权衡、异常场景应对），交给 LLM 推理。这比纯用大模型做排程靠谱得多。
2. 客户沟通：下次跟电池或钢铁行业的客户聊 AI 落地，可以拿这个案例说明“为什么工业场景不能直接套通用大模型”。客户最怕 AI 给出不准确的结果，这个工具用“宁可漏报也不误报”的设计哲学，正好对应对工业场景“宁可保守也不出错”的诉求。
3. 学习路径：这个开源项目是学习 AI Agent 在产品中落地的绝佳参考。你可以 clone 下来看它的 Agent 架构、工具调用设计、以及如何做基准测试。尤其是那个 50 个仓库 200 个 PR 的基准测试方法，可以直接复用到你评估不同排程算法方案时。

【详细讲给你听】
背景：Ruff 是 Astral 公司开发的超快 Python 代码检查工具，之前默认只开 59 条规则，很多严重问题需要手动配置才能发现。这次更新是 v0.1.0 以来首次调整默认规则集。

核心：v0.16.0 把默认规则数从 59 提升到 413，总规则数从 708 增长到 968。新规则能捕获语法错误、运行时错误等严重问题，无需任何配置就能生效。作者 Simon Willison 在自己三个大型项目上跑了一下，发现了一千多个新问题。

关键细节：1）在 sqlite-utils 项目上，Ruff 报告了 1618 个错误，自动修复了 1538 个，剩下 80 个需要人工处理。2）新规则包括要求 datetime.now() 带时区参数、禁止盲目捕获 Exception、检测无用的属性访问等。3）Astral 团队已被 OpenAI 收购，所以输出格式天然适合 AI 代理自动修复——作者用 Codex 和 Claude Code 分别升级了不同项目。

影响：对 Python 开发者来说，这意味着代码质量门槛大幅提升。但好消息是，Ruff 的自动修复功能配合 AI 助手，能让升级过程几乎无痛。作者强调，即使有完善的测试套件，这种升级也很安全。

【对你有啥用】
1. 产品判断：Astral 被 OpenAI 收购后，Ruff 的输出格式天然适配 AI 代理，这说明“AI 原生工具”的设计趋势——你的决策智能平台是否也该考虑输出格式能直接被 LLM 消费？比如排程结果直接输出 JSON 格式给 AI agent 做后续分析。

2. 客户沟通：下次跟制造业客户聊代码质量时，可以拿这个例子说明“自动化工具+AI”如何降低维护成本。客户工厂里的 MES/APS 系统代码质量同样需要这种自动化检查，你可以推荐类似思路。

【详细讲给你听】

Turbopack：Vercel 用 Rust 写的下一代打包工具，比 Webpack 快很多。Request Insights：Next.js 内置的请求性能分析工具，类似 Chrome DevTools 的 Network 面板。Canary：测试版通道，比稳定版更早发布新功能，但可能有 bug。
【对你有啥用】
